Mental model

Understand it in one minute

Open Design is not an AI model. It is not a design tool. It is a wiring layer that connects your existing coding agent to a structured design workflow. Three things compose every generation:

🧩 Skill (SKILL.md)

Defines what to build and how. The workflow, quality rules, reference files to read, checklist to run. E.g. saas-landing, dashboard, guizang-ppt.

./skills/

🎨 Design System (DESIGN.md)

Defines how it looks. 9-section brand doc: palette in OKLch, fonts, spacing, component patterns, motion, voice. E.g. Linear, Stripe, or your own brand.

./DESIGN.md

🤖 Agent (your CLI)

The coding agent on your laptop — Claude Code, Codex, Gemini CLI, Cursor. OD detects it, feeds it the composed prompt, and streams its output to the sandboxed preview.

$PATH auto-detect

📦 Artifact (plain files)

Output lives in ./.od/artifacts/<slug>/ — real on-disk files. Commit to git. Open in browser. Deploy to CDN. Export as HTML / PDF / PPTX / ZIP.

./.od/artifacts/
Quick start

Three commands

# 1. Clone and install
git clone https://github.com/nexu-io/open-design
cd open-design && npm install

# 2. Start daemon + frontend
npm run dev:all

# 3. Open in browser
open http://localhost:5173

On first load: auto-detects your coding agent, defaults to web-prototype skill + Neutral Modern design system. Type a prompt, hit Send. The 4-stage design loop begins.

Key features

What makes it different

🔌

Bring your own agent

12 agent adapters. Claude Code, Codex, Gemini CLI, Cursor, OpenCode, Qwen and more. Auto-detected on $PATH. No new model to install.

📐

Prompt choreography

Turn 1 is always a discovery form — surface, audience, tone, brand. Turn 2 is a direction picker with 5 curated palettes. No improvised aesthetics.

🗂️

Composable skills

31 SKILL.md bundles define the design workflow. Drop a folder in ./skills/, restart the daemon, it appears. Write your own in minutes.

🎨

72 brand-grade design systems

Portable DESIGN.md files — Linear, Stripe, Apple, Vercel, Figma, and 67 more. Swap in the top bar; next generation uses the new visual language.

💬

Comment mode (surgical edits)

Click any element in the live preview. Write a note. Agent edits only that element. No full regeneration needed for small changes.

📁

Git-friendly artifacts

Every artifact is plain files on disk. Commit ./.od/artifacts/ to git. Review design history in PRs. No database, no vendor lock-in.

🔑

BYOK at every layer

OpenAI-compatible proxy. DeepSeek, Groq, OpenRouter, or self-hosted vLLM — paste a baseUrl + key. Daemon never stores credentials.

✅

5-dimensional self-critique

Every artifact is auto-evaluated: Philosophy · Hierarchy · Execution · Specificity · Restraint. Low scores trigger revision before delivery.
